# মাসিক অগ্রগতি প্রতিবেদন জেনারেটর (ব্রাউজার সংস্করণ)

Python (`generate_report.py`) স্ক্রিপ্টের সম্পূর্ণ **ব্রাউজার-ভিত্তিক** সংস্করণ — কোনো
সার্ভার বা Python ছাড়াই HTML + CSS + JavaScript দিয়ে চলে। যেকোনো ব্রাউজারে খুলে
GUI থেকে তথ্য দিয়ে প্রতিবেদন তৈরি ও `.xlsx` ডাউনলোড করা যায়।

- `style.css` — স্টাইল
- `app.js` — রিপোর্ট ইঞ্জিন (Python লজিকের JS পোর্ট) + XLSX এক্সপোর্ট (SheetJS

## GitHub Pages-এ হোস্ট করা
1. এই রিপোজিটরিটি GitHub-এ push করুন (`index.html` রিপোর রুটেই আছে)।
2. Repo → **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save।
3. কিছু সেকেন্ড পরে `https://<username>.github.io/<repo-name>/` ঠিকানায় অ্যাপ চলবে।

লোকালি টেস্ট করতে: ফোল্ডারটি ব্রাউজারে সরাসরি খুললেও চলে (CDN থেকে SheetJS
লোড হয়, ইন্টারনেট লাগবে ডাউনলোডের সময়)।

3. `app.js`-এর উপরের দিকে `PASSWORD_HASH = "..."` লাইনে নতুন hex বসান।
4. Save করে GitHub-এ push করুন।

## নিয়ম (Python-এর মতোই)
1. শুক্র ও শনিবার → "সাপ্তাহিক ছুটি" (override করা যাবে না)
2. ইউজারের ছুটি → দেওয়া কারণ (ডিফল্ট "ছুটি")
3. Explicit override → ঠিক ওই তারিখেই
4. উপজেলা (প্রতিটি ২ পাশাপাশি কর্মদিবস), daily task (১ দিন), বাকি দিন → ডিফল্ট টেক্সট —
   seeded Random দিয়ে মাসজুড়ে random-ভাবে ছড়ানো
5. সব সংখ্যা/তারিখ বাংলা সংখ্যায়।

> দ্রষ্টব্য: JS-এর seed অ্যালগরিদম Python-এর Mersenne Twister থেকে ভিন্ন, তাই একই
> seed-এ Python ও ওয়েব সংস্করণের লেআউট ভিন্ন হতে পারে — তবে প্রতিটি সংস্করণ
> নিজের মধ্যে reproducible (একই ইনপুটে একই আউটপুট)।
